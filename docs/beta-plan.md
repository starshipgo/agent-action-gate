# Proposed commercial beta (not a live offer)

This is copy and a validation plan, not finalized pricing or a claim of customer demand.

| Proposed tier | What exists today | Boundary |
| --- | --- | --- |
| Free / Sandbox | Fixed public demo; small tenant-bound evaluation quota in an isolated test environment | No real external actions from the public demo |
| Developer Beta | Higher quota, audit, human approval workflow, HTTP/TypeScript SDK, guarded MCP integration | Requires server-held key and separate operator approval |

No price, payment, billing integration, SLA, enterprise identity, or adoption claim is implied. The `/quickstart` interest form asks only for email, intended integration (MCP, Dify, custom agent, other), and approximate monthly tool-call band. The server adds submission time. It does not send email or connect to a marketing provider. First-party aggregate counters track only allowlisted event names and dates; an operator can view the summary. An external developer should first test the fixed demo, then request a tenant-bound test key for a controlled integration. Review feedback, infrastructure cost, and actual usage before proposing paid prices.
